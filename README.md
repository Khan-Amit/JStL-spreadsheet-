# 📊 JStL Spreadsheet™

**Your own spreadsheet system. No Excel. No Google Sheets. Fully installable.**

## 🎯 What is JStL Spreadsheet™?

JStL is an installable web app that gives you professional spreadsheet calculations without depending on third-party software. Built with Excel logic, wrapped in your own brand.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📲 Installable | Works offline after installation |
| 🌍 Multi-Country | Bangladesh, Canada, UK, USA, India |
| 💰 Profit Calculator | VAT, sales tax, net profit, margin |
| 🧾 Tax Calculator | Progressive tax slabs per country |
| 👥 Demography | Population trends & projections |
| 📄 Text Save | Saves as formatted .jstl text file |
| 🌐 HTML Grid | Saves as printable spreadsheet |
| 🔒 No Dependencies | No Excel, no Google, no subscription |
| 🎨 Dark Blue Theme | Professional interface |

## 📥 Download & Install

### On Desktop (Chrome/Edge):
1. Visit the website
2. Click the install icon in address bar
3. Or click "Install App" button on page

### On Mobile (Android/iOS):
1. Visit the website
2. Tap "Share" → "Add to Home Screen"
3. Open from home screen like a native app
